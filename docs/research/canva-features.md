# Recursos do editor do Canva — checklist de referência

Fontes: apenas canva.com/help/* e canva.com/features/* (pesquisado em 2026-09-25). Alguns artigos bloquearam a leitura automática (HTTP 403); nesses casos a descrição vem do trecho indexado da página oficial.

## Texto

- [ ] Listas com marcadores e numeradas — [format-text](https://www.canva.com/help/format-text/)
- [ ] Espaçamento: sliders de espaço entre letras e altura de linha — [format-text](https://www.canva.com/help/format-text/)
- [ ] Atalho para aumentar espaço entre letras (Alt+Ctrl+.) — [keyboard shortcuts](https://www.canva.com/help/canva-keyboard-shortcuts/)
- [ ] Painel Efeitos: intensidade, cor, direção, transparência via sliders — [text-effects](https://www.canva.com/help/text-effects/)
- [ ] Efeito Sombra (Shadow) — [text-effects](https://www.canva.com/help/text-effects/)

- [ ] Texto curvo (Curve) com ajuste de curvatura — [curved-text](https://www.canva.com/features/curved-text/)

- [ ] Cor de preenchimento de elementos — [element-color](https://www.canva.com/help/element-color/)

- [ ] Borda: estilo (sólida/tracejada/pontilhada) e espessura — [borders/corners](https://www.canva.com/help/add-borders-round-corners/)
- [ ] Arredondamento de cantos — [borders/corners](https://www.canva.com/help/add-borders-round-corners/)
- [ ] Linhas (tecla L): espessura, estilo sólido/tracejado/pontilhado — [lines](https://www.canva.com/help/lines-in-canva/)
- [ ] Terminações de linha (setas etc.) independentes + "trocar pontas" — [lines](https://www.canva.com/help/lines-in-canva/)
- [ ] Linha reta, curva ou em cotovelo — [lines](https://www.canva.com/help/lines-in-canva/)
